# The Meet More: भक्ति-कथा रील ऑटोमेशन

हर रन में एक नई भक्ति-कथा रील (ट्रेंड के हिसाब से, 1-5 मिनट) बनती है और Themeetmore server के inbox में जाती है; पोस्ट server खुद करता है।

- `studio/RUNBOOK.md`: scheduled run के लिए पूरा निर्देश
- `studio/BRAND_AND_RULES.md`: ब्रांड और रील की शैली के नियम
- `studio/progress.json`: अब तक की बनी कथाएँ, अगला नंबर, आवाज़
- `studio/kit/`: वीडियो बनाने का कोड (`art.py` कैरेक्टर/पृष्ठभूमि, `story_template.py` साँचा, `final.py` रेंडर+मिक्स, `logo.png`)
- `videos/`: हर रन का नया वीडियो यहाँ आता है
